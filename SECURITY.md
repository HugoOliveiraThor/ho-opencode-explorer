# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities through the GitHub repository's
[private vulnerability reporting](https://github.com/ho/ho-opencode-explorer/security/advisories/new)
feature.

You can expect an acknowledgment within 72 hours. If the report is accepted,
a fix will be coordinated and released according to the severity of the
issue. Please do not disclose the vulnerability publicly until a fix has
been released.

For anything other than vulnerabilities (bugs, feature requests, questions),
open a regular issue instead.
